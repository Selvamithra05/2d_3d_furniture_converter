# 🪑 2D to 3D Furniture Reconstruction Project

This repository explores multiple approaches for converting a single 2D furniture image into a 3D model (.glb).

Each reconstruction method is maintained in a separate branch for modularity, clarity, and experimentation.

---

## 🚀 Project Overview

The goal of this project is to compare different pipelines for single-image 3D reconstruction:

- Neural reconstruction (TripoSR)
- Geometry-based reconstruction (Trimesh)
- Experimental shape modeling (Shap-E branch)

Each approach follows a different strategy to generate 3D assets from 2D inputs.

---

## 🌿 Available Branches & Pipelines

| Pipeline | Branch Name | Description |
|-----------|------------|-------------|
| 🧠 TripoSR Neural Reconstruction | `tripoSR-single-image-2d-to-3d_converter` | Uses TripoSR neural rendering for 3D reconstruction |
| 🧩 Trimesh Geometry-Based Reconstruction | `Trimesh_2d_to_3d_converter` | Generates 3D models using geometric processing |
| 🧪 Shap-E Experimental Pipeline | `shap-E` | Experimental 2D to 3D generation approach |

---

## 🛠 Tech Stack

- Python
- TripoSR
- Trimesh
- Blender (for GLB export)
- Google Colab
